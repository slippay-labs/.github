# SlipPay Labs

![Built on Stellar](https://img.shields.io/badge/built%20on-Stellar-7D00FF?style=flat-square&logo=stellar&logoColor=white)

**Non-custodial dollar settlement — for people, for agents, for companies**

What you see is what you sign. The user's own wallet signs funds directly to the recipient.

Built on **Stellar**, the open network for payments and tokenized assets, with logic running on **Soroban** smart contracts.

- *Non-custodial by construction* — SlipPay never holds funds and never has signing authority over them
- *Integrity-gated settlement* — proof-carrying transfers for autonomous agent payments
- *Three surfaces, one rail* — people, agents, and companies on a single settlement core

Code: https://github.com/slippay-labs/slippay

Stellar: https://stellar.org · Docs: https://developers.stellar.org
